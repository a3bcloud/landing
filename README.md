# landing

Pagina de venta del servicio de gestion de servidores de **A3B Cloud**.

Una sola pagina estatica, sin dependencias ni compilacion: `index.html` y nada mas. Se despliega
desde el propio panel de A3B Cloud, que es la mejor demostracion posible del servicio — si esta
pagina se cae, avisa el mismo vigilante que vigila a los clientes.

## Cambiar el contenido

Editar `index.html` y empujar a `main`. El panel redespliega solo.
