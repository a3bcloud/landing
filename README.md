# landing

Sitio de **A3B Cloud**, el servicio de gestion de servidores.

Cuatro paginas estaticas, sin dependencias ni compilacion:

| Pagina | Que es |
|---|---|
| `index.html` | Portada y precios. Es la pagina de venta |
| `sobre.html` | Quien esta detras. En un servicio cuyo argumento es que hay una persona vigilando, el anonimato lo destruye |
| `terminos.html` | Condiciones del servicio |
| `privacidad.html` | Que datos se tratan y con quien se comparten |
| `estilo.css` | Hoja compartida por las cuatro |

Se despliega desde el propio panel de A3B Cloud, que es la mejor demostracion posible del
servicio: si este sitio se cae, avisa el mismo vigilante que vigila a los clientes.

## Pendiente antes de difundirlo

1. **El correo.** Los botones apuntan a `CORREO@a3bcloud.com`, que es un marcador.
2. **Los datos entre corchetes** de `sobre.html`, `terminos.html` y `privacidad.html`:
   nombre, estado de constitucion de la LLC, horario de soporte y plazos de retencion.
   Los plazos **deben coincidir con lo que hace el sistema de verdad**.
3. **Revision legal** de los dos documentos. Llevan un aviso de borrador visible hasta entonces.

## Cambiar algo

Editar y empujar a `main`. Despues, redesplegar desde el panel.
